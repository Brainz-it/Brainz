Connexion au dépôt Git

Cette page modifie directement les fichiers du dépôt GitHub (dossier content/). Chaque enregistrement crée un commit ; le site est redéployé automatiquement.

Comment créer un token ?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : Only select repositories → choisissez ce dépôt.
  3. Permissions → Repository permissions → Contents : Read and write.
  4. Copiez le token ici. Il n'est jamais envoyé ailleurs qu'à l'API GitHub.

Ajouter des photos

Les photos sont envoyées dans content/photos/ ; les illustrations au trait (SVG) se trouvent dans content/illustrations/ et peuvent être choisies dans les champs « Illustration » de l'onglet Contenu. Cochez « Envoyer l'original » pour un SVG.

Les images sont redimensionnées côté navigateur (max px, JPEG) avant envoi pour garder le dépôt léger. Cochez « Envoyer l'original » pour ne pas convertir.

Galerie (ordre d'affichage)

Modifiez l'ordre, les légendes, ou retirez une photo de la galerie (le fichier reste dans le dépôt).
